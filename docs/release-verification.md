# Проверка выпуска

Локальная проверка выполнена 27 сентября 2026 года на отдельном проекте Docker Compose со случайными временными секретами и пустым томом PostgreSQL.

| Проверка | Результат |
| --- | --- |
| Сборка backend и frontend через `docker compose up --build` | Пройдена после исправления `backend/Dockerfile` |
| Готовность PostgreSQL перед запуском API | Пройдена: контейнер API стартовал после `db: healthy` |
| Миграции на чистой базе и повторный старт API | Пройдены: четыре миграции, повторный старт успешен |
| Постоянное хранение и восстановление из дампа | Пройдено: тестовая запись пережила перезапуск БД и вернулась после восстановления |
| Локальный HTTPS через Caddy в режиме `Production` | Пройден с локальным сертификатом: `/api/v1/health/ready` вернул `200`, session и CSRF cookie имеют `Secure` |
| Вход, пустой каталог, отсутствие ключа, пустой запрос, неизвестный ID, выход и доступ после выхода | Пройдены через frontend proxy: `204`, `200`, `409`, `400`, `404`, `204`, `401` соответственно |
| Лимит входа за reverse proxy | Пройден: шесть попыток с одного клиента дали `401` пять раз и затем `429`; подмена `X-Forwarded-For` через Caddy не сбросила лимит |
| Проверка тестовых секретов в логах | Совпадений значений пароля БД, пароля администратора и мастер-ключа не найдено |
| Backend-тесты, frontend-тесты и production-сборка frontend | Пройдены: 19 тестов backend, 3 теста frontend, сборка успешна |

Для окончательной приёмки по спринту 09 требуется опубликовать стек на сервере с публичным доменом и настроенным ключом Perplexity. На опубликованном экземпляре нужно пройти реальный поиск и повторный поиск, открыть источники и альтернативные факты, проверить фильтры и сохранность избранного и заметки. После этого следует внести фактический HTTPS-адрес в `docs/hr-handoff.md` и передать его вместе с адресом репозитория.
