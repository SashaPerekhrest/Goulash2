# Спринт 05. API базы поставщиков и деталей

## Цель

Сделать сохранённые данные доступными без обращения к ИИ: список с фильтрами и пагинацией, полные детали с источниками, избранное и заметки.

## Работы

1. Реализовать `GET /api/v1/suppliers`: первая страница доступна без параметров, размер 20 по умолчанию и 10–50 по запросу. Возвращать `items`, `page`, `pageSize`, `totalItems`, `totalPages`.
2. Добавить поиск по названию и товарам, фильтры по городу, региону, категории, товару, избранному, цене, сроку доставки и диапазону минимального заказа. Числовые значения сравнивать только в заданной валюте/единице; `includeApproximatePrices` работает как при новом поиске.
3. Добавить сортировку `created_desc`, `created_asc`, `name_asc`, `name_desc`; порядок при равенстве делать стабильным для пагинации. Для пустой базы возвращать `items: []`, `totalItems: 0`, `totalPages: 0`.
4. Реализовать `GET /api/v1/suppliers/{id}` по контракту `SourcedValue<T>`. Название, город, контакты, товары, цены, регионы, сертификаты, фотографии и условия доставки должны содержать текущие значения, источники, даты и альтернативы, если есть расхождения.
5. Отсутствующие одиночные поля возвращать как `value: null`, `status: "missing"`, `sources: []`, `observedAt: null`; отсутствие элементов коллекции — как пустой массив. В `sources[]` верхнего уровня выводить уникальные страницы поставщика.
6. Реализовать `PUT /suppliers/{id}/favorite` и `PUT /suppliers/{id}/note`. Заметка до 2000 символов, `null` удаляет её; повторное выставление избранного идемпотентно. Оба значения общие для единственной базы и не обновляются ИИ.
7. Собрать краткие карточки с датой последнего обнаружения, контактами/сайтом при наличии, `hasUnconfirmedData` и `priceIsApproximate` для показанной цены. Для недоступных внешних URL не создавать серверный прокси изображений.

## Проверяемый результат

- `GET /suppliers` не вызывает провайдера даже при фильтрации и переходе по страницам.
- Сортировка, общее количество и страницы согласованы; неверные `pageSize`, границы или единицы возвращают `400`.
- Детали показывают источник и дату для каждого внешнего значения, включая название; неподтверждённые поля имеют `external`, неизвестные — `missing`.
- Изменения избранного и заметки видны после повторного чтения и сохраняются после нового обнаружения компании.
- Неизвестный идентификатор возвращает `404`; изменение без сессии или CSRF-токена отклоняется.
