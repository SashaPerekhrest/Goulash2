# Спринт 08. Интерфейс базы и деталей поставщика

## Цель

Сделать сохранённые компании пригодными для повторного поиска, сравнения условий и выбора контакта.

## Работы

1. На `/suppliers` сразу загружать первую страницу базы. Добавить поиск по названию и товарам, применимые фильтры нового поиска, избранное, сортировку, пагинацию и переключение избранного. Единообразные карточки с товарами, ценой и доставкой позволяют сравнивать варианты без отдельного экрана сравнения; `hasUnconfirmedData` и `priceIsApproximate` отображаются так же, как в новом поиске.
2. Хранить фильтры, сортировку и номер страницы в URL приложения. При изменении фильтра сбрасывать страницу на 1; открытая по прямой ссылке страница воспроизводит тот же запрос.
3. Использовать только `GET /suppliers` для списка; не запускать ИИ-поиск при просмотре базы. Различать пустую базу и отсутствие совпадений по фильтрам.
4. На `/suppliers/:id` показать название, описание, товары, адрес, регионы работы, контакты, сайт, цены, минимальный заказ, доставку, сертификаты, изображения, все источники и даты обновления.
5. Сделать единый компонент `SourcedField`: `official` — подтверждение и ссылка, `external` — заметная надпись «Не подтверждённая информация» и ссылка, `missing` — «Нет данных». Применить его и к названию. Показывать дату получения и альтернативные наблюдения при расхождениях.
6. Для коллекций без значений показывать понятное «Нет данных» на уровне раздела. Сломанное внешнее изображение скрывать; ссылки открывать безопасно. Не загружать изображения через backend.
7. Добавить изменение избранного и общей заметки; обновлять UI после подтверждения сервера, при ошибке сохранять или восстанавливать прежнее состояние. Ограничить ввод заметки 2000 символами.

## Проверяемый результат

- База открывается с уже сохранёнными компаниями при отключённой интеграции; поиск, фильтры и пагинация не вызывают провайдера.
- URL страницы воспроизводит состояние списка; сортировка и переходы по страницам согласованы с общим количеством.
- В деталях все внешние поля имеют значение с источником и датой либо «Нет данных»; официальные и сторонние сведения различаются.
- Избранное и заметка сохраняются после перезагрузки и последующего нового поиска той же компании.
